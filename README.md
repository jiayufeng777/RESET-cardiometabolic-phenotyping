# RESET-cardiometabolic-phenotyping
Main analysis code for cardiometabolic phenotyping
LCA was conducted using R package poLCA. The conditional probabilities (P[phenotype | class]) of each binary-defined metabolic phenotype across the latent classes were shown by R package ComplexHeatmap. The decision tree model was implemented using the rpart package in R. The differential expressed proteins analyses were implemented in the R package limma .
